# 🏃‍♂️ CorriDome

CorriDome è un gioco **endless runner** sviluppato in HTML, CSS e JavaScript.

Guida Dome nella sua corsa infinita, evita gli ostacoli, raccogli le stelle e cerca di battere il tuo record! ⭐

Il gioco è semplice da giocare ma diventa sempre più difficile: la velocità aumenta man mano che accumuli punti. 🚀


## 🎮 Come si gioca

L'obiettivo è correre il più lontano possibile senza colpire gli ostacoli.

### Controlli

- ⌨️ **Spazio / Freccia Su** → Salta
- 📱 **Tocco dello schermo** → Salta


## ⭐ Funzionalità

- 🏃 Endless runner veloce e semplice
- 🌟 Sistema di punti
- 🪙 Raccolta stelle bonus
- 📈 Difficoltà crescente
- 🏆 Salvataggio del record nel browser
- 📱 Supporto per dispositivi mobili
- 💻 Funzionamento senza installazione
